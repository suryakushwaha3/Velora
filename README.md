## 📖 About

Velora Chat is a modern Android messaging application built using **Kotlin**, **Jetpack Compose**, and **Firebase**. It offers secure email authentication, real-time messaging, a clean Material 3 interface, and follows the MVVM architecture for a scalable and maintainable codebase.

---

## ✨ Features

- 🔐 Email & Password Authentication
- 👤 User Registration (Sign Up)
- 🔑 Secure Login
- 🔄 Forgot Password
- 💬 Real-Time Messaging
- 🔥 Firebase Firestore Database
- 👥 User Profile Management
- ⚡ Fast & Responsive UI
- 🎨 Material 3 Design
- 🌙 Dark & Light Theme Support
- 🧭 Navigation Compose
- 🏗️ MVVM Architecture
- ☁️ Firebase Backend
- 📱 Modern Android UI with Jetpack Compose

## 🚀 Installation

### 1. Clone Repository

```bash
git clone https://github.com/suryakushwaha3/velora-chat.git
```

### 2. Open Project

Open the project in **Android Studio**.

### 3. Firebase Setup

- Create a Firebase Project
- Enable **Authentication**
- Select **Email & Password**
- Enable **Cloud Firestore**
- Download `google-services.json`
- Place it inside the `app/` folder

### 4. Run

Sync Gradle and run the application.
